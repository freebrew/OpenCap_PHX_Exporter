**Description (2,054 chars):**
```
OpenCap Slidesheet brings your directional drilling slide sheet workbook into Chrome so you can track surveys, BHA hours, wellbore proximity, 3D well trajectories, and daily field reports in one workspace.

What it does
Full slide sheet and well setup workbook: open your local Excel slide sheet folder, edit surveys, slide intervals, downlinks, pipe tally, and daily costs right in the browser, and export a clean handoff back to Excel whenever you need it.
Direct FieldCap sync: pull job details, crew manifest, BHA equipment, inventory, daily slide and rotate metres, and ticket costs using your existing FieldCap login.
Proximity gauges and daily corridor views: see live distance and direction to plan, motor output, bit projections, and each day's drilled corridor at a glance.
Interactive 3D Wells: review your planned path, drilled trajectory, formation tops, and anti-collision offset wells in 3D, with filters for site, separation factor, and center-to-center distance.
Daily morning reports and email drafts: generate morning reports and mini summaries and open ready-to-send drafts in Outlook, Gmail, or your mail app.

How to use it
1. Click the OpenCap Slidesheet icon to open the workspace in a browser tab.
2. Choose your local job folder containing your Slide Sheet workbook.
3. Pull fresh FieldCap data using your existing browser session, update surveys and daily entries, review 3D well paths, and prepare daily reports.
4. Save locally at any time or export a handoff workbook back to your folder.

Privacy
Your job data stays on your computer and inside your browser storage. FieldCap sync uses the session you are already logged into and never asks for your password. Mailbox sign-in is optional and used only when you choose to create an email draft. Nothing is sold or sent to third-party analytics.

Independent tool
OpenCap Slidesheet is an independent, unofficial directional drilling tool. It is not affiliated with PHX Technology, FieldCap, or Pason Systems.

Support: https://github.com/freebrew/OpenCap_PHX_Exporter/issues
```

## Privacy Tab (Saved in Dashboard)

**Single purpose:** Provides a browser-based directional drilling slide sheet workbook that syncs read-only job data from FieldCap, displays proximity gauges and 3D well paths, and generates daily field report email drafts.

**Permission justifications (all 11 saved):**
- `storage` — Stores cached FieldCap CSV pulls, job-to-folder links, user mail client preferences, and optional sign-in session state locally on the user's device.
- `unlimitedStorage` — Stores multi-sheet workbooks, survey tables, well plans, anti-collision reports, restore points, and daily report images exceeding the 10 MB default quota.
- `alarms` — Runs a 1-minute periodic read-only check against an already-open FieldCap tab (`fieldcap-cdn.phxtech.com`) and supports the bundled exporter timer.
- `downloads` — Saves generated daily report `.eml` drafts, fallback CSV exports, and the optional Classic Outlook helper ZIP (`phx-outlook-host.zip`).
- `downloads.open` — Opens a generated `X-Unsent: 1` `.eml` daily drilling report draft directly in desktop Outlook / mail client.
- `scripting` — Registers and runs the read-only FieldCap page reader on `*.phxtech.com` tabs and runs same-origin read-only FieldCap OData requests when needed.
- `activeTab` — Reads the active FieldCap tab's Job ID when the user initiates a sync.
- `webRequest` — Read-only observation exclusively on `*.phxtech.com` when endpoint diagnostics are enabled.
- `identity` — Optional OAuth 2.0 sign-in (`launchWebAuthFlow`) for Microsoft 365 / Gmail report drafts or StrapSheets shift snapshots.
- `nativeMessaging` — Optional local Windows helper (`com.phx.outlook`) for Classic desktop Outlook drafts with inline images and attachments.
- `Host permissions` — `fieldcap-cdn.phxtech.com` / `*.phxtech.com` for read-only FieldCap sync; Microsoft/Google mail API hosts solely for optional report draft creation.

**Data usage disclosures:** PII, Financial & payment info, Authentication info, Personal communications, Website content. All 3 Developer Program Policy certifications checked.
