Part 1 · Chrome intake valve

Capture without retyping

FieldCap does not expose every useful field on one public endpoint. The exporter combines three techniques so the pack is complete enough for the pad.

OData fetches

Job, crew, BHA, inventory, ActivityLogs, and tickets — pulled with your active browser session.

XHR / Fetch spy

Intercepts FieldCap’s own traffic for hour and metric fields that never show up on public endpoints.

DOM scrape

Reads the live BHA grid when the UI holds the truth — then normalizes into typed CSVs.

Export Role in the workbook
Job details Identity, contacts, land, rig, directional constants → Setup
Crew / personnel Names, emails, phones, roles → Setup crew manifest
BHA equipment Serials, hours, metres, fatigue → DD Tools + Data motors sync
Inventory Tool status and hour fields for job tooling
Slide / rotate by day ActivityLog-derived daily metres per BHA — matches FieldCap’s Slide Sheet tab
Ticket costs by day Calendar daily ticket totals → Costs form / Costs sheet (CSV wins on match)

Part 2 · Standalone .xlsm cockpit

Part 3 · Directional console

Surveys meet the plan

The Slidesheet is where measured depth marches down the page — plan targets beside you, live projections from the last survey to the bit, and Comments that tell the directional hand what to do next stand.

Proximity gauge

Plan center, survey marker, projected-to-bit. Gravity mode (Inc ≥ 5°) for UP/DN + LT/RT; magnetic mode near vertical with PRP distance.

Sail + geo window

Waypoint TVD corridor and lateral budget feed both the dial and the emailed corridor PNG — one vertical story with Data’s wellbore position.

BURR → slide advisor

Active target → build-up rate required → metres to slide / remain to rotate → required TF → Comments like Sliding 12.25m @ L90 · BURR 2.40, corrected by |cos(TF)|.

Run lifecycle

End-of-run archives Data to a well-named PDF, clears day fields, clones a fresh Slidesheet — no “Copy of Copy of FINAL v3.”

EMAIL that survives Outlook

Light fixed-width HTML of the ops block people already know, plus a full corridor PNG attachment — not one crushed megaimage.

Same maths, two surfaces

Corridor renderer shares plan/proximity helpers with the on-sheet gauge. The dial you drilled by and the picture you emailed do not disagree.

Field-hardened macros

Protection-aware unprotect/work/reprotect, flicker-free screen guards, shortcuts for new Slidesheet and PDF when gloves are on.

Install the loop

Independent, unofficial, MIT-licensed. Not affiliated with PHX Technology or FieldCap — built to make their data portable into the sheet that already runs the well.

1 · Chrome extension

  1. Install .OpenCap Data Exporter from the Chrome Web Store (v3.1.8) — one click, no developer mode.
  2. On FieldCap, open the popup → pick the workbook folder → Fetch & Build into OpenCap\.
  3. Prefer source? Clone OpenCap_PHX_Exporter and load src/chrome-extension/ unpacked.
chromewebstore.google.com → .OpenCap Data Exporter → Add to Chrome

2 · Slide Sheet workbook

  1. Open Slide Sheet - Demo.xlsm (enable macros).
  2. Confirm CSVs landed beside the file under OpenCap\.
  3. Click REFRESH CSVs on Setup (or REFRESH on Data / DD Tools).
  4. Import plan / AC as needed, then drill on the Slidesheet.
